# 星轨 · 声音博物馆 · 前端

产品定义见 `../PRODUCT.md` 与 `../产品定义.md`。视觉参考稿见 `../设计参考/`。

## 跑起来

前端现在**依赖后端**，两个都要起：

```bash
# 终端 1
cd ../backend && mvn spring-boot:run        # http://127.0.0.1:8081

# 终端 2
npm install
npm run dev                                  # http://127.0.0.1:5174
```

开发服务器把 `/api` 和 `/audio` 代理到后端，所以前端代码里只认这两个前缀，
换后端地址不用动任何组件。

## 埋下一段（`/bury`）

产品定义里那条「埋声音的人」的主线。四样东西齐了才算一件展品，所以表单就是这四样：
**声音、名字、故事、语境（地点 + 录制日期）**，加一个版权勾。

**版面是「一件器物 + 它的著录牌」**，不是一列往下堆的表单：

- 左栏是器物：一组**同心细环**（和首页那个井口同一套几何，`ring-in` 从外到内依次亮一次），
  你的声波**横穿环心**（比环宽出约 50px）。还没录时，环里就是那句邀请。
- 右栏是著录牌：上边一条 1px 黄铜线、下边一条 hairline、牌面一层几乎看不出的顶光。
  四个字段的**值直接排在牌面上，不聚焦时没有框**，只有一条几乎看不见的基线；
  聚焦时才浮出黄铜下划线。整块只有一个 elevation 装置，不叠卡片阴影。
- 窄屏（≤880px）自动叠成一列：器物在上，著录牌在下。

- **声音**两条路：现场录（`getUserMedia`）或选一个文件。
  选文件会在浏览器里解码成 16k 单声道 WAV 再上传 —— 后端只认 WAV，
  而用户手上多半是手机录的 m4a。
- **10–60 秒、故事 ≥15 字、日期不能是未来**：客户端先说一遍，服务端再裁决一遍。
  客户端的提示只是为了让人早点知道，改请求绕不过服务端。
- **展签不给用户写**。留空由 `SignService` 从原文里截取（只做减法）。
  让用户手写展签就得解释「必须是原文的子序列」这条规则，那是编辑工具，不是博物馆界面。
- **交出去那一下**：声波往下沉并压平（`scaleY` 收到 0.06，700ms），整块牌同时让开，
  井口留着 —— 东西是从那里下去的；沉到底才换画面，结果写在牌上，编号先落定。
  失败时这一下立刻撤回，页面还给用户。
- 交上去之后先过机器审核，结果有三种：**进馆**（给展品链接）、
  **转人工复审**、**没通过**（都带原因，内容留在页面上可以改完再交）。
  器物那一栏同时用一句话说它现在在哪：**它下去了 / 它在等一个人 / 它还在你手上**。
- **交完不留人**：进馆和转人工的，等编号落定之后自己走过去（2.2 秒，
  点牌上任何一处就取消）；**没通过的不动** —— 那一条有动作要做，把人跳走才是尴尬。
- **删得掉**：「我的声音」里每条都有删除入口，删之前先把后果说清楚
  （「它下面有 N 条回音，会一起消失」）。只有埋它的人能删，审核流水不删。
  这三种结果来自 `ExhibitDetail` 里的 `status` / `auditNote` ——
  上传响应必须带上审核结论，否则界面只能说「已提交」，那是在骗用户。

## 打捞循环

打捞是**全站**的一件事，不是首页的一件事：

- `composables/useDraw.js` 拿着时间轴（垂下 → 勾住 → 提起 → 摊开），
  `components/DrawVeil.vue` 由 `App.vue` 渲染，所以换页不会把幕布一起卸掉。
  跳转藏在第 1700ms，路由的 out-in 转场躲在仪式后半段，人看到的是连续的一场戏。
- 落下时 URL 上带 `?from=draw` —— 这是「这一件是捞上来的」的唯一凭据。
  从馆藏点进来时没有它，页面就不会假装你是捞到的。
- 展品页和历史之声页的页脚都有「再打捞一段」，不用退回首页。
  连着捞时组件会被复用，两个视图都监听了 `route.params` 重新取数。

**别把幕布搬回首页**：首页一跳转就会被卸载，仪式会被切成两半。

### 界面的声音：打捞三记，埋下一记

打捞是点击触发的，所以浏览器允许出声。三记都在幕布的一生之内落完，
然后什么都不放 —— 位置留给展品自己，不做持续衬底：

| 时刻 | 声音 | 文件 |
| --- | --- | --- |
| 0ms | 垂下：低频起音 + 空气感（1.8s） | `audio/ritual/descend.wav` |
| 800ms | 勾住：一记很轻的实音（1.6s） | `audio/ritual/catch.wav` |
| 1500ms | 提起：一声很轻的上行（0.9s） | `audio/ritual/lift.wav` |

三段由 `tools/gen-audio.mjs` 合成（**不是真录音，也没有版权问题**），
落在 `backend/data/audio/ritual/`。三记在 2.4 秒内全部收干净 ——
展品自己的声音大约就在这时起来，之后不该再有任何衬底和它抢。
系统开了「减少动态效果」的人不播这三记。

**埋下只有一记**：`audio/bury/settle.wav`（1.3s，低频 66→43Hz 往下走 + 一记很短的闷响）。
打捞是向上的三记、勾住、末段归位；埋下是向下的一记、收束、落定即静 ——
两边的声音要能听出是同一套，所以用同一个合成器、同一套收尾。

幕布本身只有四样东西：一条垂线，线落下去之后留在空气里的那道很淡的余晖，
一个被勾住的光点，三层涟漪。余晖是**静态**的 —— 落下时最亮，随后退到 0.15
就不再变，直到幕布抬起，所以它不构成第二个「在动的东西」。
**星空是静止的**（`StarField.vue`，不进动画循环）：屏幕上同一时刻只有一个东西在动，
那个东西应该是声音。

## 复审台（`/admin`）

管理后台**不铺星空**。impeccable 的规则是「按界面选模式，不是按产品选」：
访客界面是 Experience 面（让作品领场、界面退后），
复审台是 **Operate 面**（要密、要能扫、要能敲键盘）。
一片会闪的背景放在审核队列后面只会妨碍读字。

访问方式：直接打开 `/admin`，输入服务端的 `ADMIN_TOKEN`。
口令只存 `sessionStorage`（关掉标签页就没了），不放 localStorage ——
共用电脑上不该长期留一份。

它能做三件事：看队列、通过／驳回（驳回要填原因，会记进流水）、看审核流水。

**访客界面里没有通向复审台的链接**，这是有意的：参观的人不需要知道后台在哪。

## 三条不能破的约束

1. **波形是真的。** 那 720 个点由后端从 PCM 采样里抽出来（`WavSupport`）。
   不要在前端手画波形。
2. **展签只做减法。** 由后端的 `SignGuard` 强制：展签必须是全文的字符子序列。
   前端只负责显示，不做任何文本改写。
3. **声音先于文字。** `ExhibitView` 里故事延迟 1.3 秒淡入；但如果浏览器拦下了自动播放，
   就立刻显示——内容不能因为自动播放策略而消失。

## 状态处理

接了后端之后，每个页面都必须处理三态。统一用 `StateNote`：

```html
<StateNote v-if="loading">正在整理目录…</StateNote>
<StateNote v-else-if="error" error :on-retry="run">{{ error }}</StateNote>
<StateNote v-else-if="!items?.length">馆藏还是空的。</StateNote>
<ul v-else>…</ul>
```

`useAsync` 的 `loading` 初值是 `true`（而不是 `false`）——
否则首次渲染时 `data` 还是 `null`，模板里的 `items.length` 会直接炸掉整页。

## 已知限制

- **音频全部是合成占位信号，不是真实录音**，界面上有明示。
- **语音回音还没有接 ASR**：能录、能上传、能播、时长由服务端裁决，
  但转写文本为空，所以语音内容目前绕过了文本审核。这是最大的一个缺口。
- `public/audio/` 里还留着早期前端独立演示用的 9 MB 本地音频，
  现在已经没有任何代码引用（音频全部由后端提供）。可以删掉：
  `Remove-Item -Recurse -Force .\public\audio`
