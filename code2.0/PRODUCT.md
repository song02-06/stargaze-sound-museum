## Platform

web

## Stack

- 前端：**Vue 3 + Vite**（沿用 code1.0 的前端栈）。dev/preview 都把 `/api` 与 `/audio` 代理到后端。
- 后端：**Spring Boot 3.2 / Java 17 / Spring Data JPA / H2**（沿用 code1.0）。端口 8081。
- 音频由**后端持有并提供**（`backend/data/audio`），前端不再自带音频。
- 构建方式 code-first（本会话无生图工具，`buildPath` 未写入配置）。

## Users

主要用户是 **15–30 岁的青年人**，多数在手机上、碎片时间使用。两种身份可以互相转换：

- **埋声音的人**：刚录下一段自己在意的声音，想被人听见，也想知道别人怎么接住它。
- **挖声音的人**：想听点陌生的、真实的东西，不想再刷算法推过来的内容。

## Product Purpose

一个声音博物馆：用户埋下一段 **10–60 秒**的声音并**亲手写下它的故事**，
别人可以打捞到它、听完、留下回音。

存在的理由：现在的声音产品要么把声音转写成文字后就把音频丢掉，
要么让声音变成算法流里的背景音。这个产品让普通人的声音被**保存、被重新访问**。

成功的样子：有人愿意把自己录的东西放进来，并且有人听完之后愿意回一句。

## Positioning

三条邻居抄不走的东西：

1. **声音先于文字** —— 捞上来的那一刻先出声，故事延迟 1–2 秒淡入。界面必须安静到只剩声音在动。
2. **回音可以是声音** —— 回应不只是评论，可以录一段说回去。别的平台做不到这件事。
3. **一切有出处** —— 每件展品都有编号、时间、地点；历史声音用公有领域素材，与用户投稿分开陈列。

## Operating Context

- **展品四要素**：声音本身 / 标题 / 故事 / 语境（时间＋地点）。四样齐了才叫展品。
- 内容池只有一个，访问入口有两个：主动浏览（按标签与新奇度）、漂流瓶式随机（打捞）。
- 语音回音必须先转文本才能审核，每条回音多一次 ASR 调用——这是已知且有意接受的成本。
- 展品卡片只显示**展签**（30–60 字）；点进详情才读**全文**。

## Capabilities and Constraints

完整决策见 `产品定义.md`，此处记录约束未来实现的部分：

- **时长**：主声音 10–60 秒；语音回音 10–30 秒。故事至少 15 字、上限 400 字。
- **故事由用户亲手写**。AI 只做减法：①整理（标点／错别字／口癖／断句）②压缩成展签。
  AI 输出**不得包含输入里没有的信息**——这条要写成单元测试，不是写在文档里的口号。
- **全文永久保留**；展签与全文**同一时刻只呈现一份**，一键切换，**不做并排对比视图**。
- 展签**不额外标注** AI 参与（因为只做减法）。一旦允许 AI 扩写，这条豁免立即失效。
- 回音**默认公开**；「回音收件箱」是汇总视图，**不是私信**。
- **第一版不做二级回音**（楼中楼会把博物馆变成论坛）。
- **身份**：昵称 + 本地密钥，不做邮箱密码注册，不做头像上传。
- **历史彩蛋三条保障**：新用户前 3 次打捞必出一次 / 馆藏内独立专区 / 之后低概率随机混入。
- **版权红线**：仅限本人录制或创作；禁止他人音乐作品片段；演唱类必须人工复审；
  历史素材走官方白名单，只用公有领域内容（不得使用马丁·路德·金《我有一个梦想》）。
- **隐私红线**：地点模糊到街区一级；故事里不出现可识别他人的姓名、单位、联系方式。
- **待定**：真实大模型（展签压缩目前走本地压缩器）、真实音频素材替换。
- **已落地**（后端）：三路审核（规则 DFA / AI / 人工队列）、展签压缩与守卫、
  服务端时长裁决、真实波形抽取、彩蛋保底与「本轮不重复」、HTTP Range 音频分发。
- **已落地**（ASR）：百度短语音识别接线完成。语音回音转文本后走审核三路；
  展品音频转文本做隐私检查（兑现 5.4 的承诺）。
  **转写失败时语音回音转人工复审，不放行** —— 它只有这一条审核依据。
- **已落地**（人工复审）：复审台页面 + `/api/admin/**` 口令鉴权
  （留空 = 关闭管理口，安全默认）。访客界面不提供通向后台的入口。
- **已落地**（删掉自己埋下的声音）：`DELETE /api/exhibits/{编号}` 只认埋它的人
  （所有权认会话，不认请求里写了什么）；有回音就一起删，删之前先把条数说清楚；
  **审核流水保留** —— 那是流水账，也是论文实验二的数据源。
- **仍未做**：真实素材替换、真人录音与方言验证。

## Brand Commitments

名称：**星轨 · 声音博物馆**。
语气：安静、克制、不营销。不用感叹号，不用「快来」「速来」「必看」这类词。
不编造事实——展品说明的每一个字都必须能回溯到提供者本人。

## Product Principles

1. **声音是主角，文字是注解。**
2. **展品必须有出处** —— 没有语境的收藏是归档，有语境的收藏才是展览。
3. **界面必须安静** —— 屏幕上同一时刻只有一个东西在动，而那个东西就是声音。
4. **不刷屏** —— 博物馆不追求让你看更多，而是让你停在一件展品前。
5. **不编造** —— 展签上的每一句都能回溯到作者原话。

## Accessibility & Inclusion

- 正文与占位文字对比度 **≥ 4.5:1**，大字 ≥ 3:1（参考图已按实测值校准）。
- 功能性文字**不小于 11px**。
- 键盘可达，焦点环由调色板着色；尊重 `prefers-reduced-motion`。
