1. 优先选**公有领域**或**国家档案公开**的音频，逐条填满上表。
2. 计划书第九章给出的候选方向（按公版风险从低到高排序）：
   - 罗斯福 1941 年对日宣战演讲（美国联邦政府作品，公有领域）
   - 美国国会演讲（美国国家档案）
   - 顾维钧／胡适等口述史录音（哥伦比亚大学口述史，公开可下载）
   - 斯大林 1941 年红场阅兵讲话

4. 替换后同步更新 `backend/src/main/java/com/yourname/museum/config/SeedDataRunner.java` 里的
   `sourceName` / `sourceUrl` / `licenseNote` 三个字段。
