# 视频素材

用于保存为星轨生成的视频。

## 当前预览

- [打捞完整预览 v01](生成原片/打捞-完整预览-桌面-v01.mp4)：程序渲染的动效概念预览，1280×720、30 fps、3.2 秒、静音，尚未接入前端，不是 AI 生成视频。
- [预览封面](生成原片/打捞-完整预览-桌面-v01.jpg)
- [渲染脚本](生成原片/render_draw_preview.py)：可调整分镜后重新生成，依赖 Python、Pillow、NumPy 和 FFmpeg。

## 目录

- `生成原片/`：视频生成工具导出的原始版本，保留候选素材，便于后续比较和剪辑。
- `最终成片/`：完成挑选、调色、压缩与衔接处理的视频，以及对应静态封面。

设计依据见 [视频动效设计方案](../../docs/视频动效设计方案.md)。第一期优先制作打捞过程，投稿与历史彩蛋为后续可选项。

## 命名示例

- `打捞-探入-桌面-v01.mp4`
- `打捞-等待循环-手机-v01.mp4`
- `打捞-收束-桌面-v01.mp4`
- `打捞-封面-手机-v01.jpg`

同一视频的新候选递增版本号，保留可比较的版本。不同画幅用“桌面 / 手机”区分；生成视频不带标题、编号和按钮，相关内容由前端呈现。

## 接入位置

这里是制作素材目录，不直接随网页发布。确定使用的成片再复制到 `frontend/public/videos/`，由页面通过 `/videos/文件名` 引用；待实际接入时创建该发布目录。

可在生成原片旁保存同名 `.md`，记录生成提示词、工具和版本选择理由，便于继续生成一致风格的镜头。
