# 首页留白与字体优化

本轮应用 StyleKit Editorial 的排版与组件配方：https://www.stylekit.top/zh/styles/editorial 。采用衬线/无衬线搭配、大留白、细线、无阴影展签与下划线交互，适配项目的深色主题。

修改 HomeView.vue 与 App.vue：删除声音星图、最近入馆波形及重复文案，馆藏操作集中居中；星空密度与星云强度仅在首页降低。底部保留编号、声音标题、地点与时长，完整信息仍可通过点击详情查看。

新增本地 Noto Serif SC 400 固定文案字体子集（6280 字节），运行时无需访问 Google Fonts。原始字体为 Google Fonts Noto Serif SC；授权 frontend/public/fonts/NotoSerifSC-OFL.txt。子集只供固定主标题与区块标题使用，新标题字符需要重新生成。

验证：npm run build 通过；Chrome 1366×768、1440×960、2560×1080 无横向溢出；字体加载成功；超宽屏主体限宽 1440px；键盘焦点可见；打捞加载禁用、单次请求、失败恢复、零数量与错误状态正常；无浏览器运行时异常。

预览：首页留白版-桌面.png、首页留白版-笔记本.png。截图使用项目演示数据通过模拟 API 展示，不代表真实后端实时数据。本轮仅涉及桌面首页。
