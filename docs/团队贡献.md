## 三、提交方式（每个人在自己的工作副本里）

```bash
git config user.name  "自己的作者名"
git config user.email "已关联自己 GitHub 的邮箱"

git switch -c codex/自己负责的模块
git add 具体改动的文件
git commit -m "feat: 具体完成的功能"
git push -u origin codex/自己负责的模块
```

然后在这个仓库发起 PR，合入验收分支（`main`）。

注意事项：

- 提交要围绕**完成的功能、修复和测试**组织，不规定凑多少次；
- **改注释、空提交、改作者都不算贡献**；
- 不要把整个团队成果最后重新打包成一个人的初始化提交，也不要替队友伪造作者；
- 个人分数主要来自「能解释和证明的工作」，提交数量不是公式。
