# 星轨首页设计

首页采用深空中的声音星图，保留深蓝与暖金的品牌承诺。主体限宽 1440px，仅针对桌面端。

左侧用衬线中文建立标题与打捞操作层级，数字为真实馆藏总量；右侧轨道星图呈现最近三件真实展品，点击星点进入详情。星图为几何 SVG，不模拟音频数据。底部展签复用后端真实 trace 波形、编号、时长、地点和入馆时间，不造假统计或随机波形。

暖色 #e5c895 用于声音星点与主按钮，正文 #e7e8e6，次要文字 #a4afc2。背景沿用全站静态 Canvas。首页只对自己的品牌标记作局部调整，不影响其他页布局。

保留登录入口、游客浏览、打捞全站幕布、API 错误重试、零数量空状态、键盘焦点和减弱动态效果。星点呼吸仅为装饰，减弱动态效果下关闭。


## 首屏与鼠标视差更新

首屏 hero 最低高度为 calc(100dvh - 91px)，对应首页 90px 导航和 1px 分隔线；最近入馆从下一屏开始。左侧文案整体下移 42px。右侧星图在 hero 内跟随鼠标：最大平移横向 16px、纵向 12px，俯仰 5deg、偏转 7deg，轨道额外旋转 3deg。星点链接与星图一起移动，说明文字保持固定；离开首屏、页面可见性改变时归位。每次移动最多安排一个 requestAnimationFrame，无持续循环；组件卸载取消待处理帧。减弱动态效果时不跟随且关闭过渡。

已验证 1366×768、1440×900、2560×1080：最近入馆均从视窗下缘开始，按钮完整可见，无横向溢出；鼠标移动、离开归位与减弱动态效果正常。前端构建通过。首页首屏-视差版.png 使用模拟 API 的项目演示数据。


## 星轨牵引修正（覆盖前述整图视差）

中心星锚定点、声音标签及静态圆环固定。只有双层星轨路径受鼠标牵引，使用不同深度系数产生方向性偏移与弯曲，不再平移或旋转整张图。鼠标作用范围为右侧星图；移出后以指数缓动归零，达到初始路径后停止 requestAnimationFrame。隐藏页面或开启 reduced-motion 时立即复位。浏览器验证中心坐标不变、双层路径均变化、离开后路径与初始值完全一致、减弱动效不响应指针；构建通过。


## 星轨常驻旋转

双层星轨在无鼠标操作时继续自转，外层顺时针约 90 秒一周，内层逆时针约 130 秒一周。旋转仅作用于两条路径的基底坐标，牵引偏移仍使用屏幕坐标，因此鼠标在右侧时始终向右牵引。移出后偏移缓动归零，自转继续，中心锚点和标签固定。页面隐藏、星图离开视野和 reduced-motion 下暂停；恢复时延续旋转相位。前端构建及浏览器静止自转、中心固定、减弱动效暂停/恢复检查通过。


## 毛笔字与错落排版

主标题去除标点，改为两行“循着星轨 / 听见人间”，使用本地 Ma Shan Zheng（马善政）毛笔字体八字子集，字体来源 https://github.com/googlefonts/mashanzheng ，授权随 public/fonts/MaShanZheng-OFL.txt 保存。字体文件约 6KB，不依赖在线字体请求。标题第二行右移 88px；介绍第二行右移 32px；馆藏信息缩进 88px，操作缩进 32px。增大各组上下间距，移除重复耳机建议。仅标题用毛笔字，正文仍用原无衬线字体。

已验证 1366×768、1440×900、2560×1080 本地字体加载、标题无标点、错行缩进、操作完整可见、卡片在首屏以下，无横向溢出与浏览器异常；生产构建通过。截图“首页毛笔字-错落排版.png”为项目演示数量预览。
