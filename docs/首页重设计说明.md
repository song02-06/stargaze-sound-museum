# 首页重设计

首页从居中数字与圆环改为左侧阅读、右侧声音星图、底部馆藏展签。主标题为“循着星轨，听见人间。”，暖金色实底按钮强调打捞，埋下声音为次操作。馆藏总数仍来自 API。

星图的三个声音星点与下方最近入馆对应，均可进入声音详情。几何轨道只表达空间关系，不代表地理坐标或真实数据关系。底部展签展示编号、标题、后端 trace 波形、时长、地点、入馆时间。无 trace 时留白，不生成假波形。

本轮修改 HomeView.vue，并新增 DESIGN.md 记录首页视觉规范。保留全站登录入口、游客浏览、打捞仪式与详情页；不改后端。延续静态按需绘制 Canvas；新增装饰呼吸动效支持减弱动态效果。

验证：前端 npm run build 通过；Chrome 桌面 1366×768、1440×960、2560×1080 无横向溢出；超宽屏主体 1440px；星点进入 /exhibit/0247；打捞等待禁用、单次请求、失败恢复、零数量禁用、API 错误提示及减弱动效通过。键盘主按钮焦点可见，浏览器无运行时异常。

截图使用项目 seed.json 与 audio-manifest.json 的演示内容，通过拦截 API 展示；并非连接真实后端的端到端数据验证。本轮不涉及移动端。
