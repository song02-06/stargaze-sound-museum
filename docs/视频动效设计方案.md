# 星轨 · 声音博物馆：视频动效设计方案

本方案基于当前实现及已有首页截图。交付范围为视觉与交互方案，尚未生成视频、修改前端或验证媒体播放。

## 设计方向

深空诗意 × 当代声音美术馆。沿用现有墨蓝黑底、暖白文字、黄铜著录信息、细轨道与宋体。视频集中在声音被发现、被交付的短暂时刻；聆听、阅读和录音阶段保持安静。

视觉母题是“一颗声音星点”：打捞时靠近，提交时远去，历史声音出现时转为暖金。固定镜头、克制光晕、稀疏粒子，避免高速穿梭、爆炸和持续旋转的大星球。

## 当前效果与替换建议

| 位置 | 当前实现 | 方案 |
| --- | --- | --- |
| 全站星空 | StarField.vue 静态 Canvas，App.vue 星云与暗角 | 保留。播放声音时不增加背景运动；当前静态绘制也没有持续动画循环。 |
| 首页中心井口 | HomeView.vue 同心细环 | 保留为静态视觉锚点，与视频首帧构图一致。首期无需背景视频。 |
| 打捞过程 | DrawVeil.vue 光线、光结、三圈涟漪；useDraw.js 控制请求和转场 | 首期重点替换为短视频，前端保留状态文字、错误反馈与页面交接。 |
| 展品播放 | WaveTrace.vue 按真实波形与播放进度高亮 | 保留 SVG。视频无法准确表达每件展品不同的波形和暂停状态。 |
| 录音状态 | BuryView.vue / EchoComposer.vue 状态点、时长、录音操作 | 保留实时界面，确保状态与真实录音同步。 |
| 投稿结果 | BuryView.vue 器物退场、结果文字分段出现 | 可增加局部“星点归航”视频；提交结果继续由前端显示。 |
| 历史彩蛋 | 随机打捞后进入 ArchiveView.vue，暖色视觉 | 可增加打捞尾段的暖金变体，不额外插入一段片头。 |
| 馆藏、我的声音、回音、管理端 | 列表、表单、业务操作 | 保留原生界面，普通切页沿用短淡入。 |

## A：打捞一段——首期制作

### 画面分镜

以约 2.4 秒为视觉基准，承接现有时间轴；这是目标节奏，实际结束由媒体与页面就绪共同决定。

| 时间 | 视频画面 | 前端行为 |
| --- | --- | --- |
| 0–0.4 秒 | 同首页的深空底色，中心细轨道隐去，一条极细冷白光线向下探入 | 点击后停止上一段音频，显示全屏幕布，同时发起打捞请求。 |
| 0.4–1.1 秒 | 光线末端触到一颗星点，星点逐渐亮起，周围出现一圈细涟漪 | 画面下方显示“正在星空里打捞”，文字使用 HTML。 |
| 1.1–1.7 秒 | 星点被轻轻提起，局部尘埃沿光线向上移动 | 结果已返回时，开始准备目标展品页面；尚未返回则进入等待段。 |
| 1.7–2.4 秒 | 星点稍微靠近，光晕收束为细水平光痕，整体退回深空暗底 | 目标页面数据与布局就绪后，幕布淡出，露出真实波形。 |
| 交接之后 | 视频退出，不再循环 | 继续现有声音播放与故事延迟出现逻辑；自动播放受阻时显示播放入口。 |

### 等待与交接

采用“探入片段 → 等待环 → 收束片段”的结构。等待环只保留星点极轻微的亮度变化，起止画面一致。请求快时直接进入收束；请求慢时停留在等待环，不重复整段打捞。

收束片段只在打捞结果和目标页面已准备好后播放。当前 router.push 完成不代表展品请求已经完成，接入时需要让目标页面明确报告可展示状态，避免幕布退去后又出现加载页。

先以剪辑验证三个片段接点。若浏览器切片出现可见黑帧，首期使用单段视频加稳定末帧等待，待页面就绪后直接淡出，不强求分段镜头。

视频尾帧以接近现有 --void 的暗底收尾，中心保留极淡水平光痕。真实 SVG 波形在幕布后按页面布局呈现，交叉淡入完成交接；不要求生成的视频描出某件展品的真实波形。

请求失败时立即停止仪式画面，显示真实错误并回到可重试页面。视频缺失或播放失败时使用现有 CSS 打捞效果，媒体不影响获取声音。

### 声音安排

视频交付静音版本。当前 DrawVeil 已有“垂下 / 勾住 / 提起”三记音效，分别安排在 0、800、1500 毫秒。改成可变等待后，音效需跟随阶段触发：探入时垂下、结果到达时勾住、收束时提起，不能继续依赖固定三组计时。

保留这些音效作为首版选择，展开真实展品前全部停止，不增加持续背景音乐。

## B：埋下一段——第二期可选

在左侧器物区域增加约 1.2–1.6 秒局部视频：一颗暖白星点短暂停留，沿细轨道沉向远处，最后成为星空中的一个小点。右侧结果说明保持稳定、清晰。

仅在服务端确认提交成功后播放。提交进入人工复审时，文案明确“已提交，等待审核”，星点停留在一道浅色环内；不能用已入馆的结局暗示公开成功。被拒绝或请求失败时直接展示现有反馈，不播放成功仪式。

提交成功与公开入馆是不同状态，因此首期建议先不制作这支视频，等打捞方案落地后再做。

## C：历史之声——第二期可选

复用打捞开头与等待环。结果确定为历史声音时，收束阶段让冷白星点转成黄铜色，展开一束像档案照明的暖光，随后露出历史展签。

仅随机打捞命中历史声音时使用；从历史列表主动进入时保持普通页面转场。不要额外增加观看时长，也不要在视频内生成历史文字、人物影像或虚构档案。

## 视频制作要求

- 桌面构图建议 1920×1080，手机构图建议 1080×1920，均以 24 或 30 fps 制作。它们是制作规格，不是必须下载的显示分辨率。
- 首期输出静音 MP4（H.264）和对应静态封面。先检查编码质量，再决定是否需要额外格式。
- 核心星点、轨道与光线位于中央安全区域。手机需单独构图，避免横屏裁切后光线末端消失。
- 视频无文字、无按钮、无标志；状态文字由前端覆盖，底部为其预留暗色空间。
- 初始压缩目标：桌面整套打捞素材约 2–4 MB，移动端约 1–2 MB。最终以暗部无明显色块、细线不闪烁为判断依据，不为达体积目标牺牲画质。
- 首屏先展示现有静态页面，之后空闲加载打捞素材。未加载好时点击，直接使用现有 CSS 动效，不让用户等待视频下载。
- 尊重减少动态效果偏好：显示静态状态与短淡入，不播放仪式视频；页面离开或打捞结束时停止视频。

## 可交给视频生成工具的视觉提示词

### 打捞主片

固定镜头的极简深空声音博物馆，墨蓝近黑背景，稀疏而细小的远处星点，画面中央一条极细冷白光线缓慢向下探入，在中央偏下的位置触到一颗微弱暖白星点，星点被唤醒，一圈精细涟漪轻轻扩散，星点沿光线被缓慢提起，带动极少量细尘，随后收束成一条微弱水平光痕，最后回到安静的深空暗底。光影细腻，空间深邃，留白充分，动作连续克制。无文字、无界面、无人物、无大型星球、无高速飞行、无爆炸、无镜头晃动。全片约 2.4 秒，底部保留干净暗区供网页文字覆盖。

### 等待环

与主片同一构图、同一深空底色，中央偏下的微弱星点稳定悬停，细光线保持不动，仅星点光晕有极轻微呼吸，稀疏背景星点静止。无镜头运动、无新的元素进入。制作约 1.2 秒无缝循环，首尾构图、亮度一致，无文字、无声音。

以上提示词用于表达画面，生成结果仍需剪辑和调色，不能假设工具会一次准确实现秒级分镜及无缝接点。

## 落地顺序与验收边界

第一版只制作打捞视频和封面，接入 DrawVeil.vue、useDraw.js 及展品/历史页面就绪交接，保留全站静态星空和真实 SVG 波形。第二版按实际视觉效果决定是否制作投稿与历史变体。

接入后的检查限定为会影响使用的具体失败：快慢请求是否导致视频结束后空白（调整等待与页面就绪交接）；媒体不可用是否阻塞打捞（恢复现有 CSS）；手机是否裁掉核心画面（调整竖版构图）；仪式音效是否盖住真实声音（调整停止时机）；减少动态效果是否仍被迫观看视频（使用静态分支）。本次只形成方案，未执行这些实现阶段检查。
