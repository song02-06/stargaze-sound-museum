# 用户名密码登录

## 页面与使用

导航右侧提供“登录 / 注册”，地址为 `/login`；已登录时显示用户名。“我的声音”提供退出按钮。游客仍可浏览、打捞和投稿。

用户名使用 3–24 位英文字母、数字或下划线，不区分大小写；密码为 8–128 个字符。注册页面校验两次密码一致。账号昵称可以继续在“我的声音”修改。

注册直接升级当前游客身份，保留其投稿、回音、打捞历史和消息关联。登录已有账号只切换身份，不合并当前游客内容；退出后恢复该浏览器的游客身份。注册升级后旧设备密钥会失效，退出会得到新的游客身份，已注册内容通过账号登录取回。

## 前后端实现

- `frontend/src/views/LoginView.vue`：注册/登录表单、错误提示、等待状态和游客入口。
- `frontend/src/components/AppTopBar.vue`：全站登录入口和账号展示。
- `frontend/src/views/MineView.vue`：账号说明与退出。
- `frontend/src/api/index.js`、`store/museum.js`：启动时恢复账号或游客状态、切换身份、登录失效后的状态清理。
- `backend/.../web/AuthController.java`：注册、登录、当前账号、退出 API。
- `backend/.../service/AccountService.java`：用户名规则和带随机盐的 PBKDF2-HMAC-SHA256 密码派生（600000 次）。数据库不保存明文密码。
- `backend/.../config/AccountIdentityFilter.java`：Cookie 会话确定登录身份，拒绝游客仅凭账号 ID 访问账号内容。

账号字段追加在现有 `museum_session` 表，沿用项目 Hibernate ddl-auto:update。无需清空数据库。不要删除 data/museum 数据文件。

## API

- `POST /api/auth/register`：JSON `{username,password,deviceKey}`，成功即登录。
- `POST /api/auth/login`：JSON `{username,password}`。
- `GET /api/auth/me`：返回 `{id,nickname,username}`；游客时 data 为 null。
- `POST /api/auth/logout`：使服务端登录会话失效。

登录凭证由 HttpOnly、SameSite=Lax Cookie 保存，密码不写入 localStorage。会话最长保持 7 天，服务重启后需要重新登录；账号与内容仍保留在数据库中。生产部署沿用项目 HTTPS 配置。此版本不提供密码找回或修改。
